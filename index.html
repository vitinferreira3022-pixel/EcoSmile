Sobre nós 🌱

A EcoSmile nasceu com o propósito de oferecer alternativas mais sustentáveis para a higiene bucal. Trabalhamos com escovas de dentes de bambu, incentivando pequenas mudanças que fazem a diferença para o meio ambiente.

Nossos produtos

Conheça nossa alternativa sustentável para o dia a dia.

Escova EcoSmile

Escova de dentes com cabo de bambu, uma alternativa ao plástico convencional.

Escova de Carvão Ativado

Escova de bambu com cerdas de carvão ativado, ideal para quem procura uma opção diferente para a higiene bucal.

Escova Infantil

Escova sustentável desenvolvida para crianças, com tamanho adequado para facilitar a higiene bucal dos pequenos.

Escova Extramacia

Escova de bambu com cerdas extramacias, proporcionando uma escovação suave para o cuidado diário.

Nosso compromisso com o planeta ♻️

O bambu é um material renovável e biodegradável. Nossas embalagens também são pensadas para diminuir o impacto ambiental.
